# Session Timing Report

A turn-by-turn record of a Claude Code session that worked on this project: how long the agent
worked on each request, how long the human took between requests, and token use. It is generated by
`make session-log` (`scripts/session_timing.py`, adapted from the owner's many-game-show project),
which reads the session transcript under `~/.claude/projects/`. Prompts are shortened to 70
characters, and secret-shaped strings, emails and Claude session links are redacted first. Don't
edit it by hand; a later session writes its own file instead of changing this one.
